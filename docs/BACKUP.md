# 备份、升级与恢复

## 完整备份

退出 Obsidian 后复制整个知识库文件夹，包含隐藏的 `.obsidian/`、`工作台数据/` 和 `06-附件/`。`state.json` 保存文字记录；视频、封面和截图位于附件目录，不能只复制 JSON。

「导出文字记录 JSON（不含附件）」只方便留存文字快照，不是完整知识库备份，也没有导入恢复界面。`state.previous.json` 只是上一个保存版本，不能代替长期备份。

## 恢复

1. 先退出 Obsidian，另存当前知识库，保留有问题的原文件。
2. 将完整备份恢复到一个新的文件夹，再用 Obsidian 作为知识库打开。
3. 检查稿件、封面、截图和视频是否完整，再继续编辑。
4. 飞书、服务商等密钥可能需要在本机 Obsidian 密钥库重新配置。不要把密钥写进 state.json。

只恢复文字时，应先核验完整 JSON 与当前结构兼容，再退出 Obsidian，用备份替换工作台数据/state.json；附件路径仍需要对应文件。无效存档不会自动用示例覆盖。

## 手动升级与回退

先完整备份，关闭 Obsidian，再用新安装包覆盖插件运行文件。保留现有 `feishu.json`、会话目录等本机配置，不用整个插件目录替换掉它们；发行包不包含这些文件。重开后检查保存和连接。

回退同样先备份，恢复之前的插件运行文件及与其对应的完整知识库备份。数据保存在知识库中，卸载插件不等于清除创作数据。当前无自动更新。

Markdown 文件是工作台导出的查阅副本，暂不支持反向同步。手动修改的副本会被保护，新导出放入「07-更新待合并」。
