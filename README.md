# 内容创作工作台 · Obsidian 本地版

**收藏很多，开写归零？把灵感接成作品，把好方法留给下一条。**

一个面向口播与自媒体创作者的 Obsidian 桌面插件：从自己的观点出发，管理选题、参考资料、AI 共创、稿件、封面、方法资产和发布后复盘。

![工作台首页：预置演示案例](assets/overview.png)

> 图为独立演示知识库，稿件、对话及指标均为预置案例，非真实业务效果。安装包不包含作者的知识库、账号或演示存档。

## 能做什么

- **选题变任务**：本地保存选题，也可连接自己的飞书多维表格，读取选题或预览后确认新增。
- **边聊边改**：在同一任务内确认观点、提纲、口播稿与标题；AI 对话可展开、并排或收起，候选由你编辑采用。
- **成稿归档**：定稿进入内容仓库，标题、文案与封面集中查看和取用；改稿后提示相关成果复核。
- **方法复用**：登记自己的角度、结构、开场、标题方法，保留来源；下一条按需选择，选用才进入后续共创材料。
- **视频研究**：导入本地视频，离线转写并人工修正，再用 Codex 拆解文字；方法候选确认后入库。
- **采样复盘**：记录实际发布时间，保存 24 小时/7 天采样；本地识别截图指标，人工核对后结合原稿复盘。
- **创作日常**：待办、资料整理、排期、随手记和番茄钟。

## 安装

当前预构建安装包面向 **Apple Silicon Mac（M 系列芯片）+ Obsidian 1.14.4 或更新版本**。这是早期开放版本，尚未在第二台 Mac 完整验收；Intel Mac、Windows、移动端不在当前预构建包的验证范围。

1. 从 [Releases](https://github.com/zqc16110341004/obsidian-creator-workbench/releases/latest) 下载 `creator-workbench-0.16.1-macos-arm64.zip`，解压后得到 `creator-workbench` 文件夹。不要用 GitHub 自动生成的 Source code ZIP 代替插件包。
2. 建议先在 Obsidian 新建一个专门体验的知识库。
3. 将整个文件夹复制到该知识库的 `.obsidian/plugins/creator-workbench/`。macOS 可按 `⌘⇧.` 显示隐藏文件；不要只复制 `main.js`，离线页面、转写程序等也要一起保留。
4. 重启 Obsidian，在「设置 → 第三方插件」中由你决定开启第三方插件，并启用「内容创作工作台」。[Obsidian 官方说明](https://help.obsidian.md/Extending+Obsidian/Community+plugins)
5. 点击左侧工作台图标，或用命令面板执行「打开内容创作工作台」。安装不需要运行本地网页服务。

## 第一次使用

先走最短的本地路径，不需要先连接飞书或 AI：

1. 打开「选题库」，选择本地选题，点击「新建选题」，保存位置选「仅保存本地」。
2. 选择这条选题并「开始创作」。
3. 写下自己的核心观点，确认后填写提纲，再写口播稿。可以全程手动完成。
4. 点击「确认定稿」，进入内容仓库取用文案；标题与封面可继续补齐，也可导入已有封面。
5. 关闭工作台再打开，核对刚才的内容是否保留。

初始页面带有示例内容；请新建自己的选题。示例与测试不计入正式经营统计。Markdown 笔记是查阅副本，当前修改请在工作台完成。

需要 AI 时，在共创区点击「检查连接」：本机必须已有可运行且登录 ChatGPT 的 Codex。AI 生成会使用你的订阅额度，工作台不会切换到 API Key 计费。封面生成功能另需在「封面生成设置」明确启用，仅在封面子进程增加图像工具能力，不改全局 Codex 配置。[具体前置条件](docs/SETUP.md)

## 数据与边界

- 记录保存于当前知识库的 `工作台数据/state.json`；视频、截图与封面保存于 `06-附件/`。**请备份整个知识库，文字 JSON 导出不含附件。** [恢复步骤](docs/BACKUP.md)
- AI 共创会发送本次任务必要文字与选用方法；封面生成会发送选入文字和参考图。视频转写、截图 OCR 在本机处理；视频拆解发送转写文字，不上传原视频。
- 飞书读取和确认新增需要你自己的应用与表格权限。工作台不自动发布到社交平台，不读取社交账号登录态。
- 公开博主动态需要另配数据服务及费用预算；未配置时不能作为真实自动采集使用。
- 本地核心功能可手动使用。AI、飞书、图像生成、转写各有独立前置条件，开源安装包不含账号、模型或付费服务。
- 浏览器预览使用独立的浏览器存储，AI 等原生能力为明确标注的演示，不与 Obsidian 存档同步。
- 支持 JSON 文字导出，尚无导入恢复界面；手改 Markdown 不会反向同步。尚无移动版、自动更新、云端多人协作。

## 从源码开发

需要 Node.js 22 或更新版本。运行与构建脚本仅使用 Node 内置模块，无需 `npm install`。macOS 构建 OCR 还需要 Apple 的 Swift 编译工具；视频测试若找不到 FFmpeg，会明确跳过该项集成测试。

```sh
npm run check
npm test
npm run build
npm run release
```

`npm test` 会先构建插件；macOS 上会编译本地 OCR。`npm run release` 输出与当前平台/版本对应的插件 ZIP 和 SHA256 文件到 `obsidian-dist/`。不打包用户配置、账号或知识库。当前 macOS arm64 发行包含对应架构的 OCR 程序。

浏览器预览：`npm start` 后打开终端提示的本机地址，通常为 `http://127.0.0.1:4317`。

```text
src/                 界面与创作工作流
obsidian-plugin/     本地存储、AI/飞书连接与附件处理
native/              本地截图识别与离线转写程序
scripts/             检查、构建与版本打包
tests/              自动测试与合成测试夹具
docs/               可选环境、备份、验收边界
```

问题反馈请带上插件版本、Obsidian 版本、芯片型号、操作步骤和脱敏截图。不要上传密钥、完整知识库或私人稿件。
